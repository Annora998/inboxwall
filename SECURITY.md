# Security Policy

## Reporting a Vulnerability
If you believe you have found a security vulnerability in InBox Wall, please report it responsibly. We take all security reports seriously and will respond promptly.

Please email us at: **annora998@gmail.com**

*Please do not open a public GitHub issue for security vulnerabilities.*

## Feedback and Questions
We welcome feedback, bug reports, and feature requests! For non-security related questions, suggestions, or general feedback, please:

- Open a [GitHub Issue](https://github.com/Annora998/inboxwall/issues)
- Or reach out directly via email at: **annora998@gmail.com**
